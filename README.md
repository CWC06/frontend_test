# ShotSync Frontend

This project contains a high-impact React landing page for ShotSync, showcasing pro-level basketball analytics with interactive storytelling and a dynamic 3D court background.

## Getting Started

Install dependencies and launch the local development server:

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

> **Note:** The page uses Framer Motion for micro-interactions and a custom 3D basketball court background that responds to scroll and pointer movement.
