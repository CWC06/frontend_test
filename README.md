# ShotSync Frontend

This project contains a high-impact React landing page for ShotSync, showcasing pro-level basketball analytics with interactive storytelling and a dynamic 3D court background. It now also includes a coach-facing post-game dashboard experience for immediate analysis after each matchup.

## Getting Started

Install dependencies and launch the local development server:

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Available Views

- `/` — Marketing landing page with immersive storytelling, micro-interactions, and the animated 3D court background.
- `/post-game-dashboard` — Post-game analytics dashboard with team summary metrics, live score breakdowns, shot chart, AI insights, score differential, and lineup analysis.

> **Note:** The experience uses Framer Motion for micro-interactions and a custom 3D basketball court background that responds to scroll and pointer movement on the landing page.
