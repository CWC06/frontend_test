# ShotSync Frontend

This repository contains a lightweight, CDN-powered React landing page for **ShotSync**, highlighting
data-driven basketball analytics with an interactive 3D experience built using Three.js.

## Getting started

1. Open `index.html` in your browser (no build tooling is required).
2. Ensure you have an internet connection so the CDN-hosted React, Babel, and Three.js scripts can load.

## Tech highlights

- React 18 (rendered via CDN with JSX compiled by Babel Standalone).
- Three.js powered 3D basketball centerpiece with interactive pointer tracking.
- Scroll-triggered reveal animations, responsive layout, and strong CTA sections tailored for ShotSync.
