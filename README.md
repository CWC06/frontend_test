# ShotSync Frontend

ShotSync is a landing page experience showcasing live basketball analytics with an interactive 3D court, crafted with React,
Three.js (via @react-three/fiber), and Vite.

## Getting started

```bash
npm install
npm run dev
```

The development server starts at [http://localhost:5173](http://localhost:5173).

## Available scripts

- `npm run dev` – Start the Vite dev server.
- `npm run build` – Generate a production build in `dist/`.
- `npm run preview` – Preview the production build locally.
- `npm run lint` – Run ESLint on the `src/` directory.

## Technology

- **React 18** with modern hooks and component architecture.
- **Vite** for fast development tooling.
- **Framer Motion** for subtle entrance and hover animations.
- **@react-three/fiber** and **@react-three/drei** for the animated 3D basketball court experience.
